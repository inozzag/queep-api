# Recuperação

`corpus.json` inicia a avaliação com conteúdo sintético, assuntos diversos, consultas PT/EN, conjuntos e um caso sem resposta. Cada ID tem resultados esperados definidos antes da escolha do modelo.

Medir: acerto de item conhecido no top 5 (meta ≥90%); precisão em conjuntos (meta ≥80%); recall dos conjuntos separadamente para detectar omissões; falsos positivos quando nada corresponde. Não apresentar um resultado agregado como prova de cobertura de cada formato.

Antes de fechar a onda 0: ampliar com imagens, áudio, vídeos, páginas e repositórios efetivamente acessíveis; variar a formulação das buscas; registrar tempo, custo, modelo, versão e limites. Executar em dados separados dos usados para ajustar a interpretação. Este acervo **ainda não foi processado por IA**.
